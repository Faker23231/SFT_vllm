## 2. N1 意图识别（400 条，失败 88 条 = 22%）

### 2.1 失败模式归类

1. **相邻语义意图混淆（87/88）**：混淆对几乎全是语义近邻，不是随机错误：
   - `calendar_set → alarm_set` ×7（"在妻子生日前两天提醒我" 归入闹钟）
   - `email_query → email_querycontact` ×5
   - `datetime_convert → datetime_query` ×4（"我们这里和日本的时差"）
   - `music_likeness → music_settings` ×4；`iot_hue_lightup → iot_hue_lighton` ×3
   - `audio_volume_up → audio_volume_mute` ×2（"我听不见你"）
2. **空输出仅 1 条**（invalid_rate 1.00%），格式层面无问题，瓶颈纯在**标签空间边界**。

### 2.2 高危类别（失败数 ≥4）

`calendar_set`(9)、`music_likeness`(7)、`email_query`(5)、`datetime_convert`(4)、`play_audiobook`(4)、`iot_hue_lightup`(4)、`transport_query`(4)。

### 2.3 方案与预期

- **微调**：标签封闭、类别多（59 类）、训练数据可按类造 → 种子扩写最对症。
- 预期：Macro-F1 79% → 85%+（≥5pp），重点盯高危类别配额（每类 ≥20 条训练样本）。

## 3. N2 槽位抽取（400 条，失败 200 条 = 50%）

### 3.1 失败模式归类（200 条失败的去重叠拆解）

| 错误类型 | 条数 | 占失败比 | 典型样例 |
| --- | --- | --- | --- |
| 仅槽位名错（意图对） | 107 | 53.5% | gold `date=今天` → pred `time=今天` |
| 意图错 + 槽位错 | 49 | 24.5% | 同 N1 混淆对的连带失败 |
| 仅意图错 | 32 | 16.0% | `email_sendemail` → `email_addcontact` |
| 仅槽位 value 错 | 12 | 6.0% | 极少，幻觉槽位率仅 0.62% |

### 3.2 槽位名错的细分（意图正确的 159 条中）

- **多抽槽位：92 条**，其中 **gold 本来没有槽位、模型硬抽出 50 条**（"删除接下来的活动" 抽出 `timeofday=接下来的`）；
- 漏抽槽位：52 条；
- 高频伪槽位：`time`(12)、`music_descriptor`(12)、`general_frequency`(11)、`device_type`(9)、`list_name`(9)。

根因：**抽槽粒度口径与金标不一致**（模型倾向细分 descriptor+genre，金标用粗粒度单槽），加上对"无槽意图"不识别空集。这是**语义/口径问题，不是格式问题**——JSON 合法率已 100%。

### 3.3 方案与预期（含对照实验的修正）

- 计划书 §4 的四组对照（prompt / 约束解码 / 微调 / 微调+约束解码）**仍然做，但预期修正**：JSON 合法率已 100%，约束解码对格式无增益空间；其价值只剩"用 schema 硬性禁止伪槽位"，预计只能治多抽、治不了意图混淆。主结论会落在**"微调解决槽位口径与意图"**。
- **微调**：训练数据明确"gold 空槽要输出空集"、"粗细粒度与金标对齐"（由 `03_filter.py` 的标签一致性过滤天然保证——扩写样本自标与种子标签不一致即丢弃）。
- 预期：JointEM 18% → 30%+，Slot-F1 36% → 55%+（口径对齐后 Slot-F1 的上升空间最大）。

## 4. N3 / N4（零失败样例，简述）

- **N3**：300 条约束全部通过、无空输出 → 无失败样本可归类，维持"改 prompt 不微调"。
- **N4**：F1 100% 饱和（TP=146 FP=0 FN=0），当前样本"要投诉/转人工"风险信号全显式。**行动项**：在 S2 数据合成时顺带构造"隐含风险/多轮升级"难样本（如"你们再这样我就去消协了"），重建后若仍有区分度再谈微调；本轮消融不含 N4。

## 5. 对后续步骤的具体影响

1. **消融只针对 N1/N2 训练数据**，N3/N4 数据不入训练集（`04_mix_split.py` 按节点配比时排除 n3/n4）。
2. **N2 对照实验**保留约束解码组（`--guided-decoding-backend xgrammar`），用同一服务一条命令即可，卡时忽略不计。
3. **复评判定线**（与 P6/P7 表格对齐）：
   - N1 Macro-F1 ≥ +5pp、N2 JointEM ≥ +5pp 且 gsm8k 回退 ≤ 2pp → 成功；
   - N2 Slot-F1 作为次级观察指标（预期涨幅最大）。
4. S2 合成配额向 N1 高危类别与 N2"空槽/粗粒度"样本倾斜（`03_filter.py` 按 category 配额已支持）。
